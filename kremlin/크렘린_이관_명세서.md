## 4. ★ 재현해야 할 작업 — 스파스카야 정리본

블렌더 씬을 저장하기 전에 날려서 **다시 해야 한다.** 파라미터는 전부 아래에 있다.
원본은 `05_스파스카야탑_이미지기반_원본.fbx`.

```python
# 1) 임포트 후 X −90° 회전 적용, 바닥중심 원점, 전고 10 유닛으로 정규화
#    (원본 높이 1.028 u → ×69.07 하면 71 m)

TX, TY   = 0.064, -0.032      # 탑 축
BLOB_Z   = 9.38               # 이 위는 실패한 별 덩어리 → 삭제
HALF     = 1.45               # y = TY ± 1.45 에서 bisect → 성벽 분리

# 2) 성벽 분리 후 loose 조각 제거 (탑 쪽 13,666 폴리짜리 1개)
# 3) 절단면 n-gon 4개 → 삼각분할 + 전용 머티리얼 (base color 0.42,0.20,0.15)
#    안 하면 UV 가 늘어나 텍스처가 번진다

# 4) 루비 별 신규 제작 (원본은 검은 덩어리라 못 씀)
UNIT = 7.1                    # 1 u = 7.1 m
R    = (3.75/2)/UNIT          # = 0.2641  외경 (날개폭 3.75 m)
r    = R*0.45                 # 내경
d    = R*0.18                 # 반두께
cz   = 10.0 - R               # = 9.736  중심 z (위 꼭짓점이 전고 71 m)
# XZ 평면 5각 입체별, 두께 Y. 링 10점 + 앞뒤 꼭지 2 = 20 삼각형
# 첨탑 끝(z 9.30)과 별 사이에 마운트 기둥 (반지름 0.018, 높이 0.30)

# 5) 비례 보정 — 도면 대조 결과 몸통이 너무 높다
Z_TR, Z_TGT = 6.20, 4.85      # 몸통 상단 62% → 48.5% (도면 Табл.1 실측)
# z < Z_TR       : z *= Z_TGT/Z_TR          (0.7823)
# z >= Z_TR      : z = Z_TGT + (z-Z_TR)*(zt-Z_TGT)/(zt-Z_TR)   (1.4246)
# 결과 49.0% 로 도면 48.5% 와 일치 확인됨

# 6) 50k 데시메이트 → FBX 내보내기
#    검증: 원본 1.49M vs 200k vs 50k vs 20k 를 상부 근접 렌더로 비교 → 육안 차이 없음
```

배치: `location = (1800 + 204.77, 100.55, 0)`, `rotation_euler.z = radians(47)`, 전고 71 m.

## 6. Hunyuan3D 프롬프트 — 핵심만

전문은 `ref/PROMPTS.md`, 소스 분석은 `ref/HUNYUAN_PROMPT_RESEARCH.md`.

**파이프라인 사실 (소스 확인)**
- 텍스트→3D 는 실제로 **텍스트 → 이미지 1장 → 3D**
- **`prompt[:60]` — 60자 컷.** 뒤는 버려진다
- `,白色背景,3D风格,最佳质量` 자동 부착 → 품질어 쓰면 낭비
- 텍스처 단계는 `__call__(mesh, image)` — **텍스트를 안 받는다**. delight 로 조명 제거
- 네거티브에 **`重复`(반복) · `糟糕的比例`(나쁜 비례)** 가 있어 반복 장식·극단 비례와 싸운다
- HunyuanDiT 는 중국어 우선 → 한자가 3~5배 효율적

**검증된 토큰** (우스펜스키 2회 + 블라고베셴스키 + 종탑)
| 쓸 것 | 쓰지 말 것 |
|---|---|
| `鎏金` (3/3 성공) | `金色` · `金顶` |
| `长3宽2` 비율 숫자 (2/2 성공) | `长方形` 만 |
| `扁圆` | `半球形` · **`头盔形/盔顶`**(중국 전통 지붕) |
| `四角一中` | `梅花形排列`(매화꽃) |
| `开敞拱廊内挂铜钟` (완벽 작동) | `空透`(조어) |
| `斜侧俯视`(낮은 건물) / `斜侧平视`(탑) | `斜45度俯视` · 정면 |
| 형태 서술 | **건물 고유명사** · 부정문 · `塔`·`宫殿` 등 유형명사 앞자리 |

**프롬프트로 못 이기는 것** — 블렌더에서 고쳐라
- 극단 비례 (아르세날 3.5:1, 종탑 5.4:1) → 네거 `糟糕的比例` + 정사각 캔버스 + 큐브 latent
- 정확한 개수 (0/2 실패: 5→3, 9→5) → 대칭이라 복제가 빠르다
- 미세 반복 (열주대·여장·벽돌 줄눈) → 네거 `重复`

**전략**: **프롬프트 우선.** 이미지 기반은 표면 노이즈·후면 뭉개짐·오염물이 붙어 정리 비용이 훨씬 크다.
프롬프트 오차(개수·비율)는 블렌더에서 싸게 고쳐진다.

## 9. 작업 규칙 (실수 재발 방지)

- **블렌더 임포트 전에 씬을 지우지 마라.** 이름만 붙여 쌓아라. 스파스카야 정리본을 이렇게 날렸다
- 작업 시작 전 `.blend` 저장
- 도판 스케일바는 **입면용 / 평면·단면용이 따로다.** 각각 재라
- 바르테네프는 **사젠**(1 сажень = 2.1336 m), 소련 1953년판은 **미터**
