# 모스크바 크렘린 — 모델링 레퍼런스 사진 + 실측 치수

이미지 **688장 / 1.3 GB**. 사진 576장은 Wikimedia Commons 의 큐레이션된 카테고리에서
받았고(실내·이콘·무덤은 제목 필터로 걸러냄), **바르테네프 실측 도판 83장**은
넥라소프카 도서관 API 에서 받았다. 나머지는 정사 평면도 SVG 다.
파일별 원본 제목과 라이선스는 `SOURCES.txt`, 도판 색인은
`00_바르테네프_실측도면/INDEX.md` 에 있다.

**시작점**: `_contact/index.html` 을 브라우저로 열면 건물별 8뷰가 한눈에 보인다.
뷰별 분류 현황과 채울 수 없는 칸의 사유는 `VIEWS.md` 에 있다.

> ⚠ **라이선스는 파일마다 다르다** (CC0 / CC BY / CC BY-SA / PD).
> 모델링 참고로 보는 것은 아무 문제 없지만, 사진을 **텍스처로 직접 베이킹해

## 좌표계 규약

이미 만들어 둔 씬과 좌표를 맞추려면 아래를 그대로 쓰면 된다.

| 항목 | 값 |
|---|---|
| 앵커 | 크렘린 relation 1360641 중심 **55.7516212 N, 37.6181220 E** |
| 축 | **+X = 동, +Y = 북, +Z = 위**, 단위 m |
| 지면 | z = 0 (성당광장은 z = 1.6 으로 조금 높다) |
| 블렌더 사이트 원점 | `sites.KRM["origin_m"] = (1800, 0, 0)` — 경복궁 0 / 덕수궁 600 / 화성 1200 다음 |

`yaw` 는 **+X(동)에서 반시계로 잰 건물 주축 각(도)** 이다.
정교회 성당은 동쪽을 향하므로 yaw 가 곧 제단(앱스) 방향이다.

**정면 방위각 (사진 8뷰 배정용)**

```
front_azimuth = 공칭_정면_나침반방위 − yaw        ← yaw 를 반드시 뺀다
az  = atan2(x_cam − x_bldg, y_cam − y_bldg)       (0=북, 시계방향)
rel = ((az − front_azimuth) + 180) mod 360 − 180
|rel|<22.5 Front / 22.5~67.5 Right45 / 67.5~112.5 Right / 그 밖 Back / 음수쪽 Left
```

손으로 분류해 둔 사진으로 검증한 결과 **yaw 를 빼면 108장 중 102장 일치**하고,
빼지 않으면 43% 로 떨어진다. 구현은 `tools/sort_views.py` 에 있다.
카메라 좌표는 `_camera_coords.tsv`, lat/lon → m 변환 상수는 φ=55.7516° 기준
**1° lat = 111337.3 m, 1° lon = 62772.1 m** 이다.

치수 출처는 세 가지다.
`measured` 문헌·도면에서 직접 / `counted` 세어서 유도 / `derived` 비례에서 유도(교체 필요).

**형태 요점**
- **6기둥 · 5앱스 · 5돔.** 내부를 동일 크기 정사각형 12개로 분할 → 파사드는 장변 4베이 · 단변 3베이

  양파돔은 17세기 이후 형식이라 1479년 건물에 쓰면 두 배 넘게 높아진다
- **아케이드 열주대(аркатурно-колончатый пояс)** 가 벽 중간을 가로로 두른다.
  12세기 블라디미르-수즈달 건축에서 피오라반티가 옮겨온 것으로, **이 건물에서 가장 알아보기 쉬운 요소**
- 열주대 위로 좁은 아치창, 아래로 원근 포탈(프레스코가 들어간 반원 머리)
- 드럼에 좁고 긴 아치창 + 상단 아케이드 띠 + 처마
- 돔은 **동쪽으로 치우쳐** 배치된다 (제단이 동쪽)

  Left 346(NNW) / Left45 301(WNW)

- ⚠ 좌표 판정은 이 건물에만 **쓰지 않는다**(`trust=False`). 폴더 사진 14장 중 9장은
  Commons 좌표가 건물에서 1.5 m — 카메라가 아니라 **피사체 좌표**이고, 나머지 5장도
  지오태그가 서로 모순된다(함의하는 front 가 8.5°/24°/34°/64°/66° 로 흩어진다).
  표본이 사실상 없어서 육안 판정만 쓴다
