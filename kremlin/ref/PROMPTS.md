# Hunyuan3D 프롬프트 — 모스크바 크렘린 12건 (실험 검증판)

우스펜스키 대성당 2회 실험 + GPT·Grok 교차검증으로 정리했다.
파이프라인 분석은 `HUNYUAN_PROMPT_RESEARCH.md` 참조.

## 시스템 제약 (소스 확인)

- 텍스트→3D 는 실제로 **텍스트 → 이미지 1장 → 3D**. `prompt[:60]` — **60자 컷**
- `,白色背景,3D风格,最佳质量` 자동 부착 → `8k` `photorealistic` `highly detailed` 쓰면 낭비
- 텍스처 단계는 `__call__(self, mesh, image)` — **텍스트를 안 받는다.** T2I 이미지로만 전달
- 텍스처 단계에 `delight_model` 이 있어 **조명 단어는 제거된다**
- 멀티뷰가 메시의 normal·position map 을 조건으로 받으므로 **텍스처 프롬프트에 형태 단어는 낭비**
- HunyuanDiT 는 중국어 우선 → 같은 60자에 한자가 3~5배 들어간다

## ★ 검증된 문법 (우스펜스키 2회 실험)

| 쓸 것 | 쓰지 말 것 | 근거 |
|---|---|---|
| **`鎏金`** (도금) | `金色` · `金顶` | 1차에 `金色穹顶` → 돔이 회백으로 나옴. 2차에 `鎏金` → 금색 성공. `金顶`은 "금빛 지붕"으로 읽힌다 |
| **`长3宽2`** (비율 숫자) | `长方形` 만 | 1차 평면비 1.00(실패) → 2차 1.45(목표 1.51, 4% 차) |
| **`一排小柱连拱`** | `装饰带` · `盲拱` · ~~`密集`~~ | 반복 미세요소는 크기 대비를 줘야 대형 아치화를 막는다. 단 `密集` 은 네거 `重复` 와 충돌하므로 뺐다(아래 참조) |
| **`扁圆`** (납작한 원) | `半球形` · `头盔形` | `半球形`=성 소피아 대형 단돔. **`头盔形/盔顶`은 중국 전통 지붕**(악양루)이라 정자가 섞인다 |
| **`四角一中`** | `梅花形排列` | 매화꽃이 나온다. 1차 돔 3개 → 2차 `四角一中` 으로 5개 성공 |
| **`斜侧俯视`** | `斜45度俯视` · 정면 | 45°는 너무 가팔라 벽 장식이 뭉개진다. 정면은 5돔 중 3개만 보이고 3D 가 판때기가 된다 |
| **위치는 층 적층으로** | `墙腰` · `分界线是…` | 2차에서 열주대가 벽 27% 에 붙었다. 술어형 위치 표현은 바인딩이 안 된다 → `下层实墙，中层一排小柱连拱，上层实墙` |
| 형태 서술 | **건물 고유명사** | 百度百科가 우스펜스키를 "5개의 洋葱头"로 잘못 기술 → 이름 넣으면 양파돔 소환. `升天大教堂`는 성 바실리 통칭과 충돌 |
| 긍정 특징으로 밀어내기 | 부정문 | `no onion domes` 는 양파돔을 부른다 |

**공식**: `[시점]，[재질+매스]，[핵심 형태]，[유일 식별자]`

## ★ 파이프라인이 프롬프트와 싸운다 (GPT·Grok 교차검증에서 발견)

네거티브 프롬프트를 다시 읽어보면 **건축에 직접 해로운 항목이 섞여 있다**:

```
neg_txt = "文本,特写,裁剪,出框,...,重复,...,糟糕的比例,...,恶心的比例,...,长脖子"
```

| 네거 항목 | 무엇과 싸우나 |
|---|---|
| **`重复`** (반복) | 아케이드 열주대·연속 창·여장처럼 **반복 요소 전체**. 1차에서 `装饰带`가 거대 아치로 붕괴한 진짜 원인일 수 있다. → **`密集` 을 쓰지 마라** |
| **`糟糕的比例` · `恶心的比例`** | `长7宽2` · `细高` 같은 **극단 비례**. 아르세날(3.5:1)·종탑(81 m)이 직격탄 |
| **`裁剪` · `出框`** | 도움이 된다. 다만 긴 건물은 여전히 잘리니 **`完整入镜`** 을 직접 넣어라 |

구조적 제약도 셋 더 있다:
- **T2I 캔버스가 1024×1024 정사각 하드코드** → 가로로 긴 건물이 원근으로 접힌다
- **shapegen 이 bbox 를 정사각으로 recenter 후 큐브 latent** → 다시 정육면체 쪽으로 끌린다
- **`delight_model` 이 그림자를 지운다** → 러스티케이션·벽돌 줄눈처럼 **그림자가 곧 형태**인 것은 메시에 안 파이면 텍스처로도 못 산다

**결론: 극단 비례와 미세 반복은 프롬프트로 못 이긴다.** 생성 후 블렌더에서 비율을 늘리고, 반복 장식은 포기하거나 따로 만들어라.

## 추가로 확인된 독성 토큰

| 쓰지 말 것 | 이유 | 대체 |
|---|---|---|
| `密集` | 네거 `重复` 와 충돌 | 층으로 표현 (`中层一排小柱连拱`) |
| `长7宽2` 등 극단비 | 네거 `糟糕的比例` + 정사각 캔버스 + 큐브 latent | `一字横长` · `长条形` |
| `空透` | 조어다. 원림 용어라 캡션 빈도 낮음 | **`开敞`** |
| `雉堞` + `V形凹口` | `雉堞`는 문어. 그리고 제비꼬리 실루엣은 **V(홈)가 아니라 M(이빨)** — V 라고 하면 V 를 판다 | **`M形燕尾垛口`** |
| `尖拱` | **고딕 첨두아치**를 부른다. 러시아 코코시닉과 다르다 | `双联拱窗` · `拱窗` |
| `分界线是…` | 술어라서 위치 바인딩이 안 된다. `墙腰` 와 같은 실패 | **층 적층으로**: `下层实墙，中层…，上层实墙` |
| `钟楼` `教堂` `宫殿` 등 유형 명사 앞자리 | CLIP 앞 슬롯을 먹고 **중국 건축 유형**을 소환한다(`盔顶`과 같은 메커니즘) | 재질·매스를 앞에 (`白石建筑`) |
| `俯视` (탑·성벽) | 높은 것은 층별 실루엣이 압축된다 | **`斜侧平视`** |
| `洋葱顶` (03) | 중국 T2I 에서 성 바실리의 **알록달록 사탕 양파**를 부른다 | `鎏金` 을 붙여 색을 고정 |

⚠ **방법론 한계**: 위 문법은 건물 1개 × 2회 실험이고, 두 번째에 여러 토큰을 동시에 바꿨다.
개별 토큰 효과와 시드 효과가 분리되지 않았다. **문법으로 믿되 법칙으로 믿지 마라.**

## 텍스처 프롬프트

재질·색·표면 상태에만 쓴다. **조명 단어 금지**(delight 로 지워짐), **형태 단어 금지**(메시가 결정).
부위 앵커는 최소한만 남겨서 금이 돔에, 석재가 벽에 가게 한다.

| 건물 | 텍스처 프롬프트 |
|---|---|
| 01 · 02 | `灰白色石灰岩砌块，砌缝清晰可数，轻微风化，五个鎏金圆顶，深色檐边` |
| 03 | `白色抹灰墙面，九个鎏金洋葱顶，金箔有细密竖向棱纹，深色鼓座` |
| 04 | `白色抹灰高塔，横向檐线分层，单个鎏金圆顶，铜钟深褐色` |
| 05 · 10 | `淡黄色墙面配白色石雕装饰，绿色金属屋顶，轻微风化` |
| 06 | `白色石灰岩菱形凸块，石面粗糙有凿痕，砌缝清晰` |
| 07 | `红白相间彩绘墙面，鎏金屋顶，白石雕窗框，花纹彩绘` |
| 08 | `淡黄色抹灰墙配白色柱式，绿色氧化铜穹顶` |
| 09 | `土黄色抹灰墙，白色窗框与檐线，轻微风化污渍` |

2차 `鎏金` + 앞쪽 배치 → 성공. **금색은 프롬프트 앞에 두고 `鎏金` 을 써라.**
