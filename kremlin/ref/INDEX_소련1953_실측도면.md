## 0. 도판 번호 규칙 정정

- `Таблица N = PDF 페이지 (2N + 23)` 규칙은 **Табл.1(p025) ~ Табл.34(p091) 까지만 유효**하다.
- **p093 은 Таблица 35 가 아니라 책 뒤표지**(ЦУНБ им. Н.А. Некрасова 장서 스탬프·바코드)다.
- p090, p092 를 PDF 에서 직접 렌더해 확인한 결과 **인쇄 없는 백지 뒷면(verso)** 이다.
- 따라서 **이 책의 도판은 총 34장(Табл.1–34)** 이며, 썸네일 35장 중 마지막 1장은 도판이 아니다.
- 모든 도판은 홀수 PDF 페이지에 있고 짝수 페이지는 백지 뒷면이다.

## 4. 3D 모델링용 우선순위 (크렘린)

1. **Табл.5 (p033)** — Успенский собор: 남측 입면 + 종단면 + 평면 + 현관·아케이드 상세. 이 책에서 크렘린 단일 건물에 할당된 가장 완결적인 도면 세트.
2. **Табл.8 (p039)** — Благовещенский(종단면+남측입면+2개 층 평면), Архангельский(종단면+평면+서측입면), Колокольня Ивана Великого(서측입면+2층평면).
3. **Табл.12 (p047)** — Грановитая палата(정면입면+평면+단면), Теремной дворец(정면입면+측면입면·단면+주거층평면), 크렘린 궁전 배치평면.
4. **Табл.1 (p025)** — 성벽 단면 + 주요 탑 4기 입면·평면 + 크렘린 전체 배치평면(건물 11개 위치 주기).
5. **Табл.4 (p031)** — 소보르나야 광장 17C 복원 배치평면 + 축측투상 (건물 상호 배치·높이 관계 검증용).

보조 사진 자료: Табл.2, 3, 6, 7, 9, 10, 11, 13, 14, 15, 16 (텍스처·디테일 참조).

> 주의: Табл.5·8 의 입면·단면 축척자는 **0–20 м**, 평면 축척자와 분리되어 있으므로 스캔 도면을 트레이싱할 때 도면별 축척자를 각각 캘리브레이션할 것. Табл.12 는 입면 0–10 м / 평면 0–20 м 로 축척이 다르다.
