## 3-2. ★ 축 보정 — 메시는 전부 180도 돌려야 한다

Studio 의 FBX 임포터는 `axis_forward='-Z'` 를 그대로 받지 않는다. 결과적으로 **메시 내용이
세로축 기준으로 180도(90도 두 번) 돌아서** 들어온다. 위아래는 맞고 **좌우만** 틀어진다.

- 증상: 콜리전(투명 Part)은 제자리인데 눈에 보이는 건물만 반대로 서 있다.
  계단이 정문 쪽에, 정문이 계단 쪽에 보인다.
- 처방: **MeshPart 전부** `orientation = [0, yaw + 180, 0]`. 위치·크기는 손대지 않는다.
  MeshPart 는 메시를 제 바운딩박스 중심에 놓기 때문에, 각자 제자리에서 180도만 돌면 맞는다.
- 콜리전·경계·밀폐 Part 는 엔진 좌표로 직접 만든 것이라 **건드리지 않는다**.
- `kgp_place.py` 의 `MESH_YAW_FIX = 180.0` 이 이걸 자동으로 넣는다. 다시 뽑아도 안전하다.

2026-09-17 실측으로 확인했다(플레이 스크린샷 대조).

## 4. OVERDARE 규격 대조

| 규칙 | 상태 |
|---|---|
| 파일당 ≤ 30,000 tris | ✅ 익스포터가 25,000 에서 자른다 |
| 머티리얼 1개 = 임포트 단위 1개 | ✅ 재질별로 묶어 파일 1개 = 메시 1개 = 재질 1개 |
| MeshPart 텍스처 1장 | ✅ 재질당 PNG 1장 (단색 8×8 또는 생성 소품 512) |
| 텍스처 ≤ 1024 | ✅ 최대 512 |
| FBX당 ≤ 200 메시 | ✅ 파일당 1개 |
| 벌크 임포트 ≤ 200 파일 | ✅ 180개 → 한 번에 |
| Y-up, cm | ✅ `axis_up='Y', axis_forward='-Z'`, FBX_SCALE_NONE |

## 6. MapService 등록 값 — 옛 `krm` 항목을 그대로 갈아끼웠다

맵 id 는 `krm` 을 유지한다. `M.ORDER` · `M.ALL` · 투표 UI 를 건드리지 않아도 되기 때문이다.
바뀐 것은 이름표와 가리키는 컨테이너뿐이다.

```lua
krm = {
    id = "krm", label = "KREMLIN GRAND", sub = "INDOOR / 62 x 57m",
    containers = { "KGP_GrandPalace" },
    spawnRed = "KGP_Spawn_Red", spawnBlue = "KGP_Spawn_Blue",
    bounds = { "KGP_Bound_North", "KGP_Bound_South", "KGP_Bound_East", "KGP_Bound_West" },
    rect = { minX = 97550, maxX = 103750, minZ = -2900, maxZ = 2900 },
    center = { x = 100650, z = 0 },
    groundY = 0,
    snapRise = 300, rayTop = 400, rayLen = 1600,
    zoneRadius = 900, minSpawnDist = 2500, edgeMargin = 700,
    moveScale = 0.6,
    light = merged(DAY_LIGHT, { SunBrightness = 2.0, AmbientSkyBrightness = 3.2, ... }),
    atmo  = merged(DAY_ATMO,  { FogStart = 12000, CloudAmount = 0.10 }),
}
```

**실내에 광원이 하나도 없다.** 블렌더 조명은 FBX 로 넘어가지 않으므로 밝기는 전부
`AmbientSkyBrightness = 3.2` 로 낸다. 파세트궁에서 쓰던 값 그대로다.
편집기 뷰포트에서는 이 값이 적용되지 않아 **까맣게 보이는 게 정상**이다. 플레이로 확인한다.

스폰: Red `[100650, 10, 2150]`(정문 쪽) · Blue `[100650, 10, −2550]`(계단참 아래). 48m 떨어져 있다.

## 7. 함정 (앞선 맵에서 시간을 날린 것들)

- **재임포트는 교체가 아니라 중복 발행**이고 되돌릴 수 없다. 한 번 올린 파일은 다시 올리지 않는다.
- 플레이 중에 쓰면 `level.apply` 가 타임아웃되고 Studio 메인 스레드가 잠긴다. **먼저 정지.**
- Studio 는 FBX 의 오브젝트 변환을 무시한다. 그래서 정적물은 월드를 정점에 굽고 항등으로 내보낸다.
- 판형 메시가 안 보이면 위치가 아니라 **컬링**이다. 필요하면 `DoubleSided=true`.
- 텍스처 파일명이 메시 이름과 같으면 임포트가 실패한다(Code 1315). 익스포터는 접두를 다르게 쓴다.
- `.ovdrjm` 은 UTF-16LE + BOM. 전체를 JSON 왕복시키지 말고 국소 치환만 한다.

### 8-6. ★ 스폰이 방 밖으로 튀어나가던 것 (2026-09-17)

스폰 지점을 팀룸에 넣었는데도 엉뚱한 자리에서 시작했다. 원인은 스폰 지점이 아니라
**`TeamServer` 의 흩뿌리기**다. 스폰한 사람을 스폰 지점에서 `SPAWN_SPREAD_MIN..MAX`
= **3~11m** 떨어진 곳으로 옮긴다(야외 맵 기준값). 팀룸은 14 × 6m 라 방 밖·벽 속·닫힌 문
너머로 나가 버린다.

고친 방법 : 이 세 상수를 맵 정의에서 받도록 바꿨다(`syncDef` 안에서 덮어쓴다).

```lua
SPAWN_SPREAD_MIN = d.spawnSpreadMin or 300
SPAWN_SPREAD_MAX = d.spawnSpreadMax or 1100
SPAWN_APART      = d.spawnApart or 320
```

대궁전은 `spawnSpreadMin = 0 · spawnSpreadMax = 200 · spawnApart = 150` 이다.
